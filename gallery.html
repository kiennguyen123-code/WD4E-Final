Visual Impressions of Vietnam

This gallery is built with a flexible CSS Flexbox layout. Notice how every other image features alternating corner shapes and border tones using the CSS :nth-child() pseudo-class selector. Hovering over each image activates an interactive scale transformation and shadow elevation.
